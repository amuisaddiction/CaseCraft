# 2-Minute Demo Script

**0:00–0:10 — Problem**  
“An online order goes wrong. You have the screenshots and the story, but not always the next step. HAQ turns that story into a case you can actually follow.”

**0:10–0:30 — Voice input**  
Use Wispr Flow naturally to dictate a real or fictional complaint with all personal details removed. Do not pad speech just to inflate usage.

**0:30–0:50 — Case File**  
Show extracted facts, edit one field, and mark a missing piece of evidence. If sample data is used, keep the sample label visible.

**0:50–1:15 — Ladder**  
Show the next practical step, evidence needed, source status, and official link. Explain that legal clocks appear only when verified.

**1:15–1:35 — Follow-through**  
Log a real or simulated response, then show the next action recalculated. Label simulated activity honestly.

**1:35–1:50 — Export**  
Open the printable case summary or calendar reminder.

**1:50–2:00 — Close**  
“HAQ doesn’t promise a win or file for you. It helps you keep your facts, evidence, next step, and follow-up together.”

## Evidence checklist
- [ ] Live public URL tested by another person or incognito window
- [ ] Public repository and license
- [ ] Under-2-minute demo video
- [ ] Genuine Wispr Flow usage/insights card screenshot
- [ ] Submission text describes the user, problem, and actual Wispr use
- [ ] No unsupported claims about outcomes or implementation
