# Build Plan — deadline-first

## Phase 1: Foundation
- Scaffold Vite + React + TypeScript + Tailwind.
- Create responsive app shell and case-file visual language.
- Add sample case clearly marked as sample.
- Verify `npm run build`.

## Phase 2: Core workflow
- Complaint textarea works with Wispr Flow dictation.
- Manual extraction fallback and editable Case File.
- Add AI extraction endpoint only after provider verification.
- Validate AI response against runtime schema.

## Phase 3: Ladder and follow-through
- Implement deterministic ladder engine from versioned rule data.
- Show source/verification status for every rung.
- Add response logging and update next action.
- Unit-test all state transitions.

## Phase 4: Drafts and exports
- Draft message from confirmed facts.
- Copy and mailto.
- Print stylesheet / save as PDF.
- Generate a valid `.ics` reminder using user-selected reminder dates.

## Phase 5: Submission readiness
- Test all key flows and API failure paths.
- Deploy and test the public URL in a private/incognito window.
- Check mobile layout and keyboard navigation.
- Capture genuine Wispr Flow usage evidence.
- Record demo video under 2 minutes.
- Confirm repository, license, live link, and submission description.

## Time protection
If behind schedule, preserve the working end-to-end flow and remove nonessential animation. Do not build login, a database, WhatsApp integration, or automatic filing.
